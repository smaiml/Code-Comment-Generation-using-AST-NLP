    Security rule definitions
    
          
    Example categories represented by the local demo gate.
    
          
    
            
    SEC001Dynamic code / command executionPatterns such as eval, exec, or os.system.
    
            
    SEC002Unsafe shell invocationSubprocess calls configured with shell=True.
    
            
    SEC003Unsafe deserializationUntrusted object loading such as pickle.loads.
    
            
    SEC004Hardcoded credentialsCredential-like variables assigned a literal secret instead of a secret store.
    
            
    SEC005Interpolated SQLSQL passed to an execution method with concatenated or interpolated input.
    
            
    SEC006Stored interpolated SQLSQL built in an f-string and later passed to an execution method.
